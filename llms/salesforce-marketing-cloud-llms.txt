# Salesforce Marketing Cloud Engagement

> Salesforce Marketing Cloud Engagement is an enterprise digital marketing platform for
> customer journeys, email, SMS/MMS, mobile push, content management, contact data and
> marketing automation. Its APIs are tenant-scoped: every REST call goes to
> https://{subdomain}.rest.marketingcloudapis.com and every SOAP call to
> https://{subdomain}.soap.marketingcloudapis.com, where {subdomain} is your own Marketing
> Cloud tenant subdomain from Setup > Apps > Installed Packages. Authentication is OAuth 2.0
> against https://{subdomain}.auth.marketingcloudapis.com/v2/token. Salesforce also operates
> a first-party hosted MCP server for Marketing Cloud Engagement, GA since 2026-06-02, with
> 142 tools.

Provenance: generated 2026-08-13 by the API Evangelist enrichment pipeline from this repo's
apis.yml and artifacts. Salesforce does not publish an llms.txt on its developer docs host
(https://developer.salesforce.com/llms.txt returns HTTP 403 to automated requests). A
corporate llms.txt exists at https://www.salesforce.com/llms.txt (HTTP 200) but indexes
salesforce.com marketing pages, not the Marketing Cloud API surface, so it is linked below
rather than reproduced here.

- [Authentication](https://developer.salesforce.com/docs/marketing/marketing-cloud/guide/authentication.html): OAuth 2.0 client credentials and web app flows via an Installed Package.
- [REST API overview](https://developer.salesforce.com/docs/marketing/marketing-cloud/guide/rest-api-overview.html): JSON request/response bodies; REST calls are synchronous.
- [REST reference (routes)](https://developer.salesforce.com/docs/marketing/marketing-cloud/guide/routes.html): Route prefixes per product area.
- [SOAP web service guide](https://developer.salesforce.com/docs/marketing/marketing-cloud/guide/web_service_guide.html): Legacy SOAP API for subscribers, sends and data extensions.

- [MCP tool reference](https://developer.salesforce.com/docs/marketing/mce-mcp/references): 11 categories — Automations, Campaigns, Contacts, Content, Data Extensions, Email, Journeys, Push, SMS, Tracking, Utilities.
