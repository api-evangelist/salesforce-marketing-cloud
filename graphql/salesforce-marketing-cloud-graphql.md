# Salesforce Marketing Cloud GraphQL API

Salesforce Marketing Cloud API covers email sends, automation, contacts, data extensions, journey builder, content builder, tracking events, and transactional messaging for digital marketing campaigns.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Salesforce Marketing Cloud REST API
**Documentation:** https://developer.salesforce.com/docs/marketing/marketing-cloud/guide/apis-overview.html

- Reference: https://developer.salesforce.com/docs/marketing/marketing-cloud/references
- Schema: https://github.com/api-evangelist/salesforce-marketing-cloud
